# Backend — FastAPI Application

Python + FastAPI + SQLAlchemy + Pydantic backend for the AlgorithmX platform.

**Purpose:** exposes the REST API (auth, problems, submissions, contests,
leaderboard, analytics), manages PostgreSQL via SQLAlchemy + Alembic, and
dispatches submissions to the isolated evaluator service.
